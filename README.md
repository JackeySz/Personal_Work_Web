## GitHub Pages 发布

1. 新建 GitHub 仓库，例如 `PersonalWeb`。
2. 上传本目录中的 `index.html`、`styles.css`、`assets/`、`documents/`、`.nojekyll`、`README.md`。
3. 进入仓库 `Settings` → `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后，等待 GitHub 生成公开访问地址。

如果仓库名是 `你的用户名.github.io`，网站地址会是：

`https://你的用户名.github.io/`

如果仓库名是 `PersonalWeb`，网站地址通常是：

`https://你的用户名.github.io/PersonalWeb/`
